# Release notes

## 3.0.0

First public release of the WoW Forever edition (1.60.1).

- Native character preview and gear slots for saving, equipping, and restoring fishing outfits.
- Compact actionbar-style HUD with a larger cast button, smaller lure buttons, tight spacing, and hover-only highlights.
- Vanilla-only pole and lure catalogs.
- Fishing toolbar, automatic pole and lure selection, and optional double-right-click casting.
- Configurable cast / bobber key using native interaction.
- Session and lifetime catch history, zone tracker, and trash filtering.
- Scrollable settings with inline explanations and temporary fishing audio controls.
- Native window management and a compact, fixed-width layout.
- Local CurseForge publishing with dry runs, package-only builds, and SHA-256 checksums.
- Removed unused legacy textures, configuration fields, and the inactive debug setting.
- Existing saved outfits, catches, and settings are preserved.

Supports WoW Forever only. Other WoW clients are no longer supported.
